# sd-computers 游戏内使用指南（简体中文）

面向**玩家**与**服主/管理员**的操作手册。安装、配置与汉化说明见 [README-CN.md](../README-CN.md)；给维护者看的上游合并流程见 [_zh_work/README.md](../_zh_work/README.md)。

# 一、玩家篇

## 1. 走到电脑前

对准电脑的显示器/键盘/主机，目标菜单里会出现 **「使用电脑」**（默认 1.8 米内出现）。选中它，镜头会推到屏幕前，桌面就在显示器里面。

- **同一台电脑同一时间只能一个人用**：别人在用时会提示「有人正在使用这台电脑」。
- **走开就关**：离开约 2.5 米，电脑自动收起并退回锁屏。
- 没人用的电脑，显示器上会显示**锁屏画面**；有人在用时，附近的人能看到**实时画面**（PIN 与密码框会自动打码）。

服务器默认的电脑（`configs/shared/computers.lua`）：

| 电脑 | 位置 | 谁能用 | 外观 |
|---|---|---|---|
| 米申罗警局前台 | MRPD 前台桌面 | 警察 | 现代 SD OS Pro |
| 圆堡山医疗中心接待处 | 医院前台 | 救护 | 默认外观 |
| 公共电脑 / 商用笔记本 | 地图上对应型号的显示器/笔记本 | 所有人 | 默认外观 |

> 后两台是「按道具型号」的电脑，**出厂是关闭的**，需要管理员在 `/computeradmin` →「自动电脑」里打开（见管理员篇）。管理员也可以随时放置新的电脑。

## 2. 开机、登录、桌面

1. **启动序列**：先看到系统启动画面（复古外观是 DOS 自检）。
2. **锁屏**：显示电脑名与时间。管理员如果给这台电脑设了 **PIN**，这里会出现 PIN 输入框；连续输错 3 次会锁定 60 秒（次数与时长可在 `configs/server/security.lua` 改）。**默认没有任何 PIN**——职业锁已经决定了谁能用，直接就能进。
3. **桌面**：登录用的是你的**角色**身份。你写的文档、加的照片、记的备忘录都跟着角色走，换任何一台电脑都能看到。

## 3. 基本操作

| 操作 | 键 |
|---|---|
| 起立（锁屏界面或空桌面） | `Esc` |
| 打开开始菜单 | `Ctrl` + `Esc` |
| 关闭当前窗口 | `Alt` + `F4` |
| 最大化 / 还原窗口 | 双击标题栏，或把窗口拖到屏幕顶部 |
| 关机并起立 | 开始 → 电源 → 关机 |
| 锁屏（不离开） | 开始 → 电源 → 锁定 |

窗口可以拖动、从边缘缩放；点击时钟打开日历面板，点任务栏/菜单栏上的状态图标打开快捷面板（两者位置随外观：现代在右下角，mac 在右上角，复古在底部状态栏）。

**三种外观**由这台电脑的配置决定，同一个应用在不同外观下长得不一样：

| 外观 | 屏幕上的系统名 | 感觉 |
|---|---|---|
| 现代 | **SD OS Pro** | 居中任务栏、开始菜单、圆角半透明窗口 |
| 复古 | **SD Desktop 3.11** | 1991 年的系统，装在米色 CRT 里，DOS 启动 |
| mac | **SD OS Harbor** | 顶部菜单栏、放大程序坞、红绿灯窗口按钮 |

每个角色在**每种外观**下分别记住自己的壁纸、强调色、深色/浅色偏好（设置 → 个性化）。

## 4. 应用速查

| 应用 | 能做什么 | 关键点 |
|---|---|---|
| **邮件** | 收发站内邮件 | 账号是 `名字@lsmail.com`，**共享账号**（知道密码的人在哪台电脑都能登）；一个角色最多同时登 5 个、最多创建 3 个 |
| **事件查看器** | 看这台电脑的系统日志 | 登录/输错 PIN/锁定/打开应用/发邮件/经营管理操作/入侵尝试与突破；可筛选；清空会留下一条「日志被 X 清除」（事件 1102） |
| **命令提示符** | 仿真的 `cmd.exe` + 入侵玩法 | `help` 看全部命令；`hack` 练习、`targets` 看目标、`breach` 打真目标 |
| **经营管理** | 老板菜单 | 只有该职业的老板能看到；见 §5 |
| **文件** | 文档编辑器 | 文档跟着角色走；能打印；能带签名线 |
| **照片** | 角色的相册 | 用图片链接添加，最多 200 张 |
| **浏览器** | 城市内网 | 只能打开服务器配置里的站点；见 §6 |
| **银行** | 余额、现金、交易记录 | **只读**，不能转账 |
| **公司公告板** | 职业公告 + 在岗名单 | 老板发/置顶/删除，同职业的人在任意电脑都能看 |
| **安防监控** | 看你有权限看的摄像头 | 可全屏、可拖动看四周、滚轮缩放；每次查看都会写进日志 |
| **游戏** | 扫雷、纸牌、贪吃蛇 | 每款是独立窗口；最佳成绩会保存 |
| **记事本 / 计算器 / 设置** | 便签、标准计算器、个性化 | 记事本的笔记跟着角色走 |
| **手机连接 / 信息 / 备忘录 / 通讯录** | sd-phone 联动 | 见 §7 |

### 邮件（Mail）

- 第一次用先**注册**：用户名 + 密码（至少 6 位）+ 显示名，地址就是 `用户名@lsmail.com`。
- 左边是文件夹：收件箱 / 已标记 / 草稿 / 已发送 / 废纸篓；可以回复、转发。
- 来自手机的邮件（sd-phone 联动）会带附件：照片、语音备忘录、文档。
- 发给不存在的地址会**退信**（「邮件投递子系统」发回你的收件箱）。
- 一封最多 20 个收件人；主题最多 200 字；正文最多 10000 字。
- 你在电脑前时，新邮件会弹系统通知。
- 因为账号是共享的，把密码交给同事就是「公司邮箱」；被人拿到密码也能在任何电脑登录——这也是 RP 里「泄露凭据」的来源。

### 命令提示符与入侵（重点）

打开后是一个像模像样的 `cmd.exe`，`help` 会列出所有命令：

```
ver  cls  exit  hostname  whoami  echo  title  color  dir  cd
date  time  ipconfig  systeminfo  ping  tasklist  help
hack  breach  targets
```

前面那些是仿真系统命令（`ipconfig`、`systeminfo`、`ping`、`tasklist` 都会给出这台电脑的假数据）。真正有用的是后三个：

| 命令 | 作用 |
|---|---|
| `hack <游戏> [easy\|medium\|hard]` | **练习**一局迷你游戏，不给奖励，但会记日志 |
| `targets` | 列出这台电脑上可入侵的目标（有的目标被设成隐藏，要有人「卖情报」给你命令名） |
| `breach <目标命令>` | 打**真目标**：按顺序通关它设定的每一步迷你游戏，成功后奖励由服务端发放 |

十个迷你游戏（`hack` 后面就是这些名字）：

| 命令名 | 程序 | 名字 | 玩法 |
|---|---|---|---|
| `maze` | net-maze.exe | 网络迷宫 | 在视野受限的迷宫里找数据碎片并走到出口 |
| `capture` | node-grab.exe | 节点占领 | 在节点消失前点掉足够多的节点 |
| `cipher` | cipher-lock.exe | 密码破译 | 四面转盘对齐密码 |
| `snake` | data-worm.exe | 数据蠕虫 | 贪吃蛇，吃够节点 |
| `firewall` | fw-defense.exe | 防火墙防御 | 守住服务器节点，打掉来袭威胁 |
| `evasion` | highway-evade.exe | 高速公路规避 | 在数据高速上躲开威胁 |
| `typing` | code-inject.exe | 代码注入 | 限时照抄注入载荷 |
| `signal` | sig-replay.exe | 信号重放 | 记住并重放信号序列 |
| `pipe` | pipe-route.exe | 数据包路由 | 旋转管道把数据从入口接到出口 |
| `breakout` | ice-break.exe | ICE 突破 | 打砖块，清掉 ICE 层 |

- 难度 `easy` / `medium` / `hard` 分别改变尺寸、限时、速度、命数（`configs/shared/hacks.lua`）。不给难度时用默认（`medium`）。
- **真目标**（`configs/server/targets.lua`）可以有冷却、失败冷却、需要携带物品、限定职业，成功可能触发警察报警，奖励可以是现金、物品、邮件或服主自定义的事件。奖励只在最后一步由服务端发放。
- 服务器装了反作弊：每次开局的「最短游玩时间」和「必经里程碑」由服务端按同一套难度参数推导，提前退出或跳步都算失败。

### 经营管理（老板菜单）

只有这台电脑绑定的职业的**老板**能看到。

- **员工**：名单带在线/在岗状态；可以升职、降职、解雇。
- **雇佣**：选站在电脑前的人，或输入玩家 ID；对方会收到「X 想雇佣你」的确认框（20 秒不回应自动拒绝）。
- **财务**：公司资金余额曲线、存入/支取、对账单。
- 所有操作都会写进这台电脑的系统日志。

> 需要 `sd-banking` 或 `Renewed-Banking` 才有公司资金；没有时「财务」会自己隐藏。ESX 服没有经营管理。

### 文件（文档）

- 左侧是文件列表（自己的文档 + 联动的手机文档），右侧是所见即所得的编辑器。
- 支持：字体、字号、文字颜色、标题/正文/引用、加粗斜体下划线、对齐、列表、分隔线、图片（从「照片」里选，可设大小、左右、图注）、**签名线**、页面字体。
- 文档跟着角色走；打印时按你排的版直接出纸。

### 照片

- 通过**图片链接**添加（默认允许图床：imgur、fivemanage、fmfile、discord、ibb、postimg、catbox、gyazo，见 `configs/shared/photos.lua`）。
- 每个角色最多 200 张；这些照片可以放进「文件」的文档里。
- 手机相册（sd-phone 联动后）会并排显示。

### 浏览器

服务器内网，只能打开配置里有的站点，其它地址一律「无法访问」。默认站点：

| 地址 | 站点 |
|---|---|
| `weazel.news` | 威泽尔新闻 |
| `marketplace.ls` | 交易市场 |
| `yellowpages.ls` | 黄页 |
| `directory.ls` | 商家名录 |
| `squawk.ls` | 叽喳（社交动态） |
| `laws.gov` | 法律与罚款（刑法典） |
| `stocks.ls` | 股票行情 |
| `network.help` | 「这个网络如何运作」帮助页 |

装了 sd-phone 时这些站点是**实时**的（新闻、商品、商家、动态、股价都来自手机那边的数据）。地址栏输入 `home` 回起始页。

### 安防监控

- 只列出**你有权限看**的摄像头；列表上方显示数量。
- 选中后画面在窗口里实时播放；可以**全屏**，拖动画面看四周，滚轮缩放，左右切换上一个/下一个摄像头，也有重置视角。
- 每次第一次查看都会记进这台电脑的系统日志。

## 5. 打印与纸张

能打印的应用：**记事本、文件、邮件、银行、事件查看器**（窗口里找「打印」）。

1. 打印机必须在**这台电脑 30 米内**，打印对话框里会列出可用的打印机。
2. 可以一次打 1–5 份，每份约 2.5 秒出纸。
3. 纸**不会直接给你**：它留在打印机的纸盘里（最多堆 25 份，60 分钟没人取会被丢弃）。
4. 走到打印机旁，目标菜单里选 **「取打印件」**，纸张作为物品进背包（物品名 `printed_document`，悬浮提示里有标题、谁打的、什么时候、哪台机器）。
5. 使用该物品，会展开成一张真实的 A4 页面，可以递给别人、放进仓库。
6. **签批**：文档里画了签名线的话，持有者可以签（鼠标手写，或键入名字选一种笔迹）。签名下的名字和时间由**服务端**写，不能自己改。
7. 银行对账单、系统日志、邮件这些内容由服务端按真实数据生成——打印件不能伪造。

> 服务器需要把 `printed_document` 物品加进背包（ox_inventory 的 items 表）。没有这个物品时打印会提示失败。

## 6. 手机联动（可选，sd-phone）

服务器装了 sd-phone 并且开启了联动时：

1. 打开 **手机连接**，它会往你的手机发一条**验证码通知**（5 分钟内有效）。
2. 在电脑上输入验证码 → 手机「连接」到**这台**电脑。
3. 桌面会多出 **信息 / 备忘录 / 通讯录**，浏览器站点变成实时，文件/照片/银行也会显示手机那一侧的内容。
4. 连接是按「角色 + 这台电脑」记住的，直到你在手机连接里解除。

注意：手机上这些应用要求你**身上带着手机**（默认如此），手机放仓库就看不到。

## 7. 常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 没有「使用电脑」选项 | 这台电脑有职业限制；或距离太远；或电脑被管理员移走了；按型号的电脑要在「自动电脑」里打开 |
| 提示「有人正在使用这台电脑」 | 同一台电脑只能一个人用，等对方离开 |
| 锁屏要求 PIN 但我不知道 | 管理员在 `configs/server/security.lua` 给这台电脑设了 PIN，找管理员要 |
| 打开后一片黑 / 没有界面 | 前端没有构建（`web/build` 缺失）。用发布包，或在 `web/` 里 `npm run build` |
| 输错几次 PIN 被锁了 | 默认 3 次错锁 60 秒，等计时结束 |
| 收不到手机验证码 | 手机不在身上 / sd-phone 没启动 / 验证码超过 5 分钟 |
| 打印没反应 | 30 米内没有打印机；纸盘满了（25 份）；背包满了；或者服务器没有 `printed_document` 物品 |
| 图片加不进去 | 图床不在白名单（见 `configs/shared/photos.lua` 的 `Hosts`） |
| 没有系统音效 | 该外观的 `Sounds` 被关掉了（`configs/shared/desktop.lua`） |
| 时间显示不对 | 设置 → 时间和语言：24 小时制、时区；服务器时钟与游戏一致 |

# 二、管理员篇

## 1. 权限

| 项目 | 默认值 | 说明 |
|---|---|---|
| 打开面板命令 | `/computeradmin` | `configs/shared/admin.lua` → `Command` |
| 完整权限 | `group.admin` | `Group`，同时拥有下面的 `command.computeradmin` 与编辑权限 |
| 只读权限 | `ViewGroup = false` | 例如填 `'group.mod'`：能开面板看，但不能改 |
| 编辑权限 | ACE `sd_computers.edit` | `Group` 自动拥有；要给别的组编辑权就把这个 ACE 授给它 |

## 2. 面板的七个标签页

| 标签 | 用途 |
|---|---|
| **概览** | 统计（电脑数、放置的、来自配置的、使用中的、职业锁、PIN 保护、道具、外观），按外观/按道具的分布，当前规则，本次会话的操作记录 |
| **电脑** | 全部电脑列表（来源、是否使用中、职业锁、PIN）；放置新电脑；拾取世界里已有的显示器/笔记本变成电脑；传送/移动/修改/删除 |
| **摄像头** | 架设新摄像头（直接飞过去取景）、修改、删除 |
| **打印机** | 放置打印机或拾取已有打印机/复印机 |
| **自动电脑** | 把地图上某型号的显示器/笔记本**批量**变成电脑（总开关 + 按型号开关 + 按型号指定外观） |
| **道具** | 电脑可以伪装成哪些道具；可以从面板里添加自定义模型（上限 64 个） |
| **外观** | 三种外观的预览、服务器默认外观 |

## 3. 放置电脑

- 在「电脑」标签点 **放置电脑**。系统会从你**正看着的桌面/柜台/地面**开始（6 米内），没看着合适平面就从你面前一步开始。
- 移动/旋转用**操作器**（屏幕上左侧就是完整的按键提示）：

| 键 | 作用 |
|---|---|
| `G` | 光标开/关 |
| 按住 `RMB` | 环顾四周 |
| `LMB` 拖箭头/圆环 | 移动 / 旋转 |
| `W` | 移动模式 |
| `R` | 旋转模式 |
| `Q` | 本地轴 / 世界轴切换 |
| 滚轮 | 旋转 |
| `↑ ↓ ← →` | 微调（`Shift` ×5） |
| `PgUp` / `PgDn` | 高度 |
| `X` | 吸附（0.25 m / 15°） |
| `T` | 贴地 |
| `Alt` | 放下（悬空时提示，离地高度会显示） |
| `Ctrl` + `Z` | 撤销 |
| `Backspace` | 取消 |
| `Enter` | 放置 |

- 放置完成后可以直接给它起名、设职业锁、PIN、外观、应用清单（都保存在数据库，优先于配置文件）。

## 4. 拾取世界里已有的道具

「电脑」/「打印机」标签里选 **拾取**：

- 瞄准任何**游戏本来就有**的显示器、笔记本、打印机或复印机，按 `Enter` 或**左键**确认。
- **不会生成任何东西**：就站在那里的那个道具变成电脑/打印机。
- 电脑会自动生成在离它 60 米内的客户端上。

## 5. 摄像头与屏幕

**摄像头**：点「架设」后镜头会让你飞过去，你看到的画面就是它以后拍的画面，`Enter` 保存，再填名称/区域/谁能看。

**绘制屏幕**（给道具画一块能显示画面的屏幕）：

| 键 | 作用 |
|---|---|
| `LMB` 拖 | 在玻璃上从一个角拖到对角 |
| 按住 `RMB` | 环顾四周 |
| 滚轮 | 推入/拉出 |
| `Q` / `E` | 后仰 / 前倾 |
| `↑ ↓ ← →` | 微调（`Shift` 加大步长） |
| `G` | 贴合到表面 |
| `F` / `V` | 正视图 / 侧视图（侧视图下滚轮贴合玻璃，`Q/E` 调倾角） |
| `Ctrl` + 滚轮 | 缩放 |
| `H` | 显示/隐藏画面（检查贴合） |
| `R` | 道具的另一面 |
| `Ctrl` + `Z` / `Del` | 撤销 / 重新开始 |
| `C` | 复制配置片段（可以直接贴进配置文件） |
| `Backspace` / `Enter` | 取消 / 保存 |

> 视角太偏时无法拖拽，按 `F` 重新面向屏幕。

## 7. 排查清单

1. **打不开电脑**：看 `server.cfg` 是否 `ensure` 在框架、`ox_lib`、`oxmysql`、target 资源之后；看服务端控制台有没有 `configs/*.lua` 报错。
2. **界面空白**：确认 `web/build/index.html` 存在（发布包自带；源码分支需要自己构建）。
3. **打印件拿不起来**：背包里没有 `printed_document` 物品定义 → 按 README 的 Printers 一节加物品并放图片。
4. **按型号的电脑没反应**：「自动电脑」标签里的总开关是关的（出厂默认），打开后写入数据库，优先于配置文件。
5. **没有经营管理**：检查电脑条目是否设了 `boss`，玩家是否该职业的老板；ESX 不支持。
6. **没有公司资金**：需要 `sd-banking` 或 `Renewed-Banking`。
7. **看不到摄像头**：摄像头条目的 `groups` 是否包含该玩家职业；电脑条目是否设了 `cameras = false`。
8. **网页打不开**：自有 `url` 站点必须是 https，且对方站点允许被 iframe 嵌入（`X-Frame-Options`/`frame-ancestors` 会挡住大部分大站）。
